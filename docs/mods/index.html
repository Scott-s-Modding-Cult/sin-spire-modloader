Mods

Every mod here works with the Sin Spire Mod Loader. Most come with the patch already; the rest you can add from the Mod Manager.

1. Patch the gameDownload SinSpire-ModLoader-Patch.exe (always the newest) and run it. It finds the game and installs the loader, and keeps itself up to date after that.
2. Get modsHold Shift while launching, or run Mod Manager.bat, and use the Get Mods tab. Or unzip a download into the game's Mods folder.
3. PlayTick the mods you want in the Mod Manager. Changes take effect on the next launch.

Mods are made for Sin Spire and need your own copy of the game. This project isn't affiliated with the game's developers. Third-party assets are listed in the credits.
